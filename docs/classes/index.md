# Classes

Classe é a profissão do personagem: ela define as habilidades e os equipamentos que ele pode usar.
No PepsRO estão disponíveis **todas as classes do Ragnarok oficial até a 4ª classe**, mais a linha nova **Druida → Karnos → Alitea**.

## Como evoluir

Todo personagem começa como **Aprendiz** e vai mudando de classe conforme sobe de nível.
A mudança é feita no **Job Master**, em Prontera (153, 193), **sem missões de mudança de classe**: basta ter o nível pedido.

| Etapa | Nível pedido (base / classe) | Exemplo |
|---|---|---|
| Aprendiz → 1ª classe | classe 10 | Aprendiz → Espadachim |
| 1ª → 2ª classe | classe 40 | Espadachim → Cavaleiro |
| Renascer (2ª → Aprendiz T) | 99 / 50 | Cavaleiro → Aprendiz T |
| 1ª T → Transclasse | como a 1ª e a 2ª classe | Espadachim T → Lorde |
| 2ª classe ou Transclasse → 3ª classe | 99 / 50 | Lorde → Cavaleiro Rúnico |
| 3ª → 4ª classe | 200 / 70 | Cavaleiro Rúnico → Cavaleiro Draconiano |

!!! tip "Renascer é opcional"
    Dá para ir direto da 2ª classe para a 3ª no nível 99/50. Quem renasce passa pela Transclasse antes.

!!! warning "Depois de renascer, o caminho é o mesmo"
    Quem renasce precisa seguir a mesma linha de antes. Um Cavaleiro que renasce só pode virar Espadachim T e depois Lorde.

!!! warning "Antes de mudar de classe"
    O Job Master exige que **todos os pontos de habilidade estejam gastos**.
    Ele também entrega de graça as habilidades de missão da classe ("habilidades platinum").

### Níveis máximos

| Fase | Nível de base máximo | Nível de classe máximo |
|---|---|---|

## Classes expandidas

Não renascem. Os níveis pedidos são diferentes das classes normais.

| Linha | Evolução | Nível pedido |
|---|---|---|
| Taekwon | Taekwon → Mestre Taekwon → Mestre Estelar → Mestre Celestial | 2ª: classe 40 · 3ª: 99/50 · 4ª: 200/70 |
| | Taekwon → Espiritualista → Ceifador de Almas → Asceta das Almas | 2ª: classe 40 · 3ª: 99/50 · 4ª: 200/70 |
| Superaprendiz | Superaprendiz → Superaprendiz EX → Hiperaprendiz | Superaprendiz: base 45 · EX: 99/99 · Hiper: 200/70 |
| Justiceiro | Justiceiro → Insurgente → Guerrilheiro | Insurgente: 99/70 · Guerrilheiro: 200/70 |
| Ninja | Ninja → Kagerou / Oboro → Shinkiro / Shiranui | Kagerou/Oboro: 99/70 · 4ª: 200/70 |
| **Druida** | **Druida → Karnos → Alitea** | Karnos: 99/70 · Alitea: 200/70 |
| Invocador | Invocador → Animista | Animista: 200/60 |

!!! info "Druida, Karnos e Alitea"
    É a linha mais nova do Ragnarok e já está no PepsRO, com a Alitea até o nível 275.

## Classes bebê

As classes bebê (inclusive as expandidas e o Invocador bebê) também estão liberadas no Job Master.

## NPCs que ajudam

Todos ficam em Prontera.

| NPC | Onde | O que faz |
|---|---|---|
| Job Master | 153, 193 | Muda de classe e renasce |
| Resetadora | 150, 193 | Reseta atributos, habilidades ou os dois, de graça |
| Mestre do Plágio | 168, 179 | Ensina a habilidade copiada pelo Plágio/Reprodução no nível máximo |
| Montarias de Classe | 126, 200 | Dá a montaria da classe (Peco Peco, Grifo, Dragão, Mado Gear ou Lobo) |

Para as builds de cada classe, veja [Builds](builds.md).
