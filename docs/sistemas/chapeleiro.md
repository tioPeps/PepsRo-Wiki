# Chapeleiro

O **Chapeleiro - Topo** (Prontera 146, 170) faz chapéus em troca de **missões de caça**.

## Como funciona

1. Escolha o chapéu no menu. O NPC mostra a descrição, e o nome é clicável para ver o item.
2. Aceite a missão. Ela aparece na janela de missões (**Alt+U**).
3. Derrote os monstros pedidos e volte ao NPC para receber o chapéu.

- Cada chapéu pode ser feito de novo depois.
- O **Elmo de Vanargand** também pede um **Chapéu de Rideword +9** ou mais na entrega.
