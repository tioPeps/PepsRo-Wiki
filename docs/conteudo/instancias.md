# Instâncias

## Regras do PepsRO

- **Todas as instâncias aceitam grupo de 1 pessoa.** Dá para fazer sozinho.
- **Recarga de 15 minutos** em todas as instâncias. Os cronômetros internos curtos (dentro da instância) continuam como no oficial.
- O **Warper** (Prontera 159, 192) tem o menu **Todas as Instâncias**, que leva direto para a frente do NPC que cria cada uma.
