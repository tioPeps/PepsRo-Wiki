# Edda do Biolaboratório

Instância feita para o PepsRO, baseada no **Modo Batalha** da Edda do Biolaboratório.

| | |
|---|---|
| **Entrada** | Sierra, em Juno (yuno 216, 345) |
| **Nível mínimo** | 170 |
| **Grupo** | A partir de 1 pessoa. Só o líder cria a instância |
| **Duração** | 2 horas |
| **Recarga** | 15 minutos |

## Como funciona

1. **7 salas** com monstros do Biolaboratório. Quando a sala é limpa, todo o grupo vai para a próxima.
2. No **Necrotério**, fale com a Sierra para invocar a MVP **Espadachim Anônima**.
3. Quando a MVP morre:
    - aparece um **baú** com chance de Caixa de Reagentes, Caixa de Arquivos ou Caixa de Bioarmas;
    - a Sierra dá **3 Arquivos de Biopesquisa e 5 Fragmentos de Experimento** a cada membro.

!!! info "Diferenças da versão oficial"
    Os monstros não usam habilidades, as salas não têm as mecânicas especiais do oficial e não existe o Modo Expedição.
